# VetCare Huila

Sistema de gestión clínica y bienestar animal — proyecto SENA 2026.

## Estado inicial

El proyecto está en su etapa inicial. El archivo `EsquemaSQL.sql` es el punto de partida para definir la base de datos.

## Trabajo con el repositorio

1. Crear los archivos y componentes del proyecto en esta carpeta.
2. Revisar los cambios en el panel **Cambios de Git** de Visual Studio.
3. Guardar los avances con una confirmación (commit) y un mensaje descriptivo.
4. Usar **Insertar / Push** para enviar las confirmaciones a GitHub.

Los archivos temporales de Visual Studio y los resultados de compilación se excluyen mediante `.gitignore`.
