La documentación acompaña el desarrollo del proyecto formativo y permite explicar las decisiones, reproducir los procedimientos y verificar los resultados.

## Registros disponibles

- [Bitácora del proyecto](BITACORA.md): procedimientos realizados, resultados y pendientes.
- [Formato de registro de procedimientos](FORMATO_PROCEDIMIENTO.md): plantilla para nuevos avances.
- [Guía del proyecto formativo](../PROYECTO_FORMATIVO_MVP_VETERINARIA.md): caso de estudio y entregables exigidos.

## Organización de los próximos entregables

Estos entregables están pendientes; la tabla define su organización, no acredita su elaboración.

## Registro de evidencias

Cada avance debe indicar objetivo, fecha, responsable, pasos, resultado, evidencia y pendientes. Las capturas deben ocultar credenciales, claves, cadenas de conexión y datos personales. Conservar en Git la documentación y el código; los secretos de configuración deben permanecer fuera del repositorio.

Los cambios de documentación se guardan junto con el avance al que corresponden. Una configuración creada no equivale a una función probada: registrar ambos estados por separado.
